# college-lms

Read [the project contract](../../../docs/DESIGN.md) for the active task. Resolve project paths relative to the repository root.

Scope content by college, curriculum/regulation, branch, semester, subject and topic. A student's current semester must not block authorized backlog subjects. Switching academic scope must reset or safely re-scope conversation context.

Retrieve approved material and present explanations with resolvable document/page citations. Mark supplemental general knowledge and abstain when source coverage is insufficient. Code examples and expected output are illustrative unless an isolated execution tool actually ran them.

Past-paper analysis computes topic/question counts from a named deduplicated corpus, with years/sample size; never present a prediction guarantee. Paper download authorization matches retrieval authorization.

Test same-name subjects in different curricula, backlog access, absent source, unpublished paper, citation correctness and stale context. Deliver the ticket's learning journey. Full curriculum population and code execution remain separate work.
